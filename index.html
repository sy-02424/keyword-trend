키워드 관심도 비교

키워드를 넣고, 사람들의 관심도가 최근 90일 동안 어떻게 달라졌는지 그래프로 확인해 보세요.

영어 위키백과 문서 제목으로 찾아요. 예: Kimchi, Coca-Cola, Netflix

    시간 흐름에 따른 관심도

    기간 내 최댓값 = 100 ·

      키워드를 넣고 [비교하기]를 누르면 최근 90일 그래프가 여기에 그려져요.

      • 위키 조회수 = 정보 탐색 관심도이며 검색량이 아님
      • Data: Wikimedia Pageviews API (영어 위키백과, 봇 제외 사람 조회, 하루 단위 집계)

      🔌 이 화면이 쓰는 API

      아직 부른 API가 없어요. [비교하기]를 누르면 여기에 실제로 부른 주소와 "새 탭에서 원본 JSON 보기" 링크가 나타나요.
