# 키워드 관심도 비교 대시보드

캠페인 키워드나 브랜드 이름을 최대 5개까지 넣으면, 기간 동안 관심도가 어떻게 달라졌는지 한 그래프로 비교해 주는 마케터용 대시보드입니다.

- v1: 영어 위키백과 조회수(Wikimedia Pageviews API, 키 없음)
- v2 예정: 네이버 데이터랩 API로 교체

> 위키 조회수는 정보를 찾아본 관심도이며 검색량이 아닙니다. 하루 단위로 집계되므로 실시간 데이터가 아닙니다.

## 기능

1. 키워드를 5개까지 넣으면 입력창 아래에 하나씩 보이고, 6번째를 넣으려 하면 입력이 막히면서 "최대 5개까지"라는 안내가 뜬다.
2. [비교하기]를 누르면 키워드마다 색이 다른 선 그래프가 그려지고, 세로축 최댓값이 100으로 표시된다.
3. 화면 맨 아래 "🔌 이 화면이 쓰는 API" 상자에 키워드마다 실제로 부른 주소와 "새 탭에서 원본 JSON 보기" 링크가 보인다.
